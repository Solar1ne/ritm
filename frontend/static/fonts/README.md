# Шрифты Ритма

Шрифты размещены локально, чтобы интерфейс не зависел от доступности Google Fonts и не отправлял запросы за шрифтами третьей стороне при открытии приложения.

- Golos Text variable, 400–900: https://github.com/google/fonts/tree/main/ofl/golostext. Copyright 2019 The Golos Text Project Authors. Лицензия: `GolosText-OFL.txt`.
- Prata Regular: https://github.com/google/fonts/tree/main/ofl/prata. Copyright и лицензия: `Prata-OFL.txt`.

Оригинальные TTF загружены 17.10.2026 из официального репозитория Google Fonts, без изменения глифов. Полные SIL Open Font License 1.1 сохранены рядом с каждым шрифтом. Prata используется для крупных заголовков; Golos Text — для действий, данных и основного текста.
